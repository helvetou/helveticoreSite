2. Source files (build vs reuse)

Legend: BUILD = in-house (TDD, Fail-Fast) · REUSE = standard library / 3rd party.

2.1 src/protocol-adapters/ — Protocol Adapters (BUILD)

FileContains
protocol_adapters/frame.pyStrict Pydantic v2 models: Frame, Source, Measurement (extra="forbid", bounded unit_id, non-empty measurements).
protocol_adapters/errors.pyCorruptedPayloadError(reason_code, detail, offending_field) — the Fail-Fast exception.
protocol_adapters/base.pyRawPayload frozen dataclass (input contract) + ProtocolAdapter ABC (parse()).
protocol_adapters/modbus_common.pyRegisterDefinition + decode_holding_registers() (shared FC03 decode + bounds checks).
protocol_adapters/modbus_rtu.pycrc16() + ModbusRtuAdapter (RTU ADU parsing, Fail-Fast).
protocol_adapters/modbus_tcp.pyModbusTcpAdapter (MBAP/TCP ADU parsing, Fail-Fast).
protocol_adapters/__init__.pyPublic API re-exports (Frame, Measurement, adapters, crc16, RegisterDefinition, …).
conftest.pyPytest bootstrap: makes the package importable.

2.2 src/edge-analytics/ps/ — Edge Analytics PS (BUILD)

FileContains
edge_analytics_ps/stats.pyAggregate dataclass + compute_stats() (mean/rms/min/max/last/count).
edge_analytics_ps/aggregate.pyaggregate_window() (N frames → 1) + dedupe() (consecutive dedup).
edge_analytics_ps/window.pyWindowAggregator (time-window buffering, deterministic on collected_at).
edge_analytics_ps/__init__.pyPublic API re-exports.
conftest.pyPytest bootstrap: makes edge_analytics_ps + protocol_adapters importable.

2.3 testbench/ — Virtual test bench (BUILD)

FileContains
meter_simulator/meters.pySTANDARD_REGISTER_MAP (4 registers), EnergyMeter, MeterFleet (deterministic 50-meter simulator).
meter_simulator/frame_builders.pybuild_rtu_response() / build_tcp_response() (raw Modbus ADU builders).
meter_simulator/__init__.pyPublic API re-exports.
conftest.pyPytest bootstrap: makes meter_simulator + protocol_adapters importable.
