GeberLMS

The Learning Management System used to sell the courses produced by Helveticore OÜ (Estonia): catalogue, enrollment, coupons, VAT/OSS invoicing, e-testing and LLM-generated quizzes — with admin, tutor and learner roles, in four interface languages.

Architecture at a glance

  • Runtime — the whole app runs on a single Cloudflare Worker; static assets served by Pages.
  • UI — shadcn-svelte + Tailwind CSS v4 (component library, light/dark mode).
  • Data — D1 (SQLite) via Drizzle ORM: 15 tables, migrations 0001_init → 0006_course_metadata.
  • Files — R2 bucket geberlms-files for learner uploads and course resources.
  • Auth — sessions on Workers + accounts in D1; PBKDF2-SHA256 (Web Crypto).
  • Money — integer cents only; discount on the net price, then VAT at the buyer's country (OSS).

Pure domain layer (src/lib/domain)

Framework-agnostic business logic, tested in isolation with Vitest — the TDD core of the platform.

Money & pricing

  • vat.ts — EU VAT rates, buyer-country rule, non-EU = 0.
  • coupon.ts — % / fixed amount, 100 % free, expiry, usage cap.
  • pricing.ts — discount on net, then VAT (OSS).
  • invoice.ts · payment.ts — invoicing and Payoneer flow.

Access & roles

  • roles.ts · authz.ts — admin / learner / tutor permissions.
  • user.ts · session.ts · password.ts — accounts, sessions, PBKDF2.
  • guardianship.ts — tutor ↔ learner links and visibility.

Learning

  • catalog.ts · content.ts — course → modules → lessons → resources.
  • enrollment.ts — single-payer enrollment resolution.
  • progress.ts · quiz.ts · upload.ts — progress, e-testing, uploads.

Platform

  • activity.ts — audit journal (login, deposit, correction, payment).
  • dashboard.ts — learner / tutor dashboards.
  • i18n.ts — FR / EN / AR / DE, RTL for Arabic.

Actors & roles (FR-01…FR-07)

Admin

Operator. Manages courses, resources, coupons, accounts and payments. No public self-signup: learner and tutor accounts are created by the admin.

Learner (apprenant)

Takes courses; either financed by a tutor or self-paying (self_payer flag). Follows progress and uploads documents.

Tutor (tuteur)

Finances one or more learners and follows their progress — sees only the learners it finances.

What is implemented

Functional areas

  • Catalogue — course / module / lesson / resource CRUD, reversible hide, public catalogue flag (FR-10…FR-14).

Commerce & platform

  • Coupons — % or fixed, 100 % free, expiry, usage cap (FR-42…FR-45).
  • Invoicing — integer-cent pricing, VAT/OSS, invoice generation (FR-46/FR-47, BR-01…BR-05).
  • i18n — FR / EN / AR / DE interface with RTL for Arabic.
  • Deployment — Cloudflare Worker build + D1 migrations + seeds.
