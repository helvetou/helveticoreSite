IT/OT convergence: securing Modbus flows over MQTT

By Malek Haroud· 2026-11-23· 4 min read

The operational floor speaks Modbus. The cloud speaks MQTT. The hard part is not the protocol — it is the trust boundary you draw between the two.

Two worlds, two assumptions

On the OT side, Modbus RTU/TCP was designed for a trusted serial or LAN segment: no authentication, no encryption, a flat register model. On the IT side, MQTT is a publish/subscribe transport that scales well but does not secure itself either. The moment you bridge the two, you inherit both gaps at once.

The naive integration — read a register, wrap it in JSON, publish it — creates a path where a corrupted packet or a spoofed device flows straight into the data lake. That is the exact failure mode an IIoT gateway must eliminate.

Normalize, then publish

EdgeStream-GW solves this with a strict internal contract, the Frame. Every protocol adapter turns raw bytes into a validated Frame or fails fast with a structured CorruptedPayloadError. Nothing invalid crosses the boundary, and nothing is silently “repaired”.

Only after normalization does the gateway publish northbound. For MQTT we use Sparkplug B, which adds the industrial semantics plain MQTT lacks: namespaces, device states (birth/death), and a Protobuf payload. For SCADA, OPC UA provides the equivalent client/server + PubSub story. The key principle: the north boundary speaks industrial standards, not ad-hoc JSON.

Three security seams to design now

  • TLS on the north link — encryption and server authentication between the gateway and the broker.
  • Device authentication — each meter or PLC proves who it is before its telemetry is trusted.
  • Keys in hardware — long-lived credentials belong in a hardware keystore (that is the role of Fog-Crypto Core), not in a text file on the flash.

The takeaway: IT/OT convergence is not a wiring problem, it is a contract problem. A strict Frame, Fail-Fast parsing, and Sparkplug B / OPC UA publication give you a boundary you can reason about — and audit.
